# Plastic Pyrolysis Prediction and Optimization

This project combines an existing XGBoost oil-yield model with a calculated
specific-energy-consumption (SEC) model and a Streamlit interface for
multi-objective exploration. NSGA-II searches for conditions that maximize
predicted oil yield and minimize estimated SEC.

The model outputs are estimates for exploring candidate process conditions;
they are not experimental guarantees. SEC is based on explicit energy-model
assumptions that can be updated when measured data is available.

## Run the application

Open PowerShell in this folder and install the project dependencies:

```powershell
python -m pip install -r requirements.txt
```

Then start Streamlit:

```powershell
python -m streamlit run app.py
```

Open the local URL printed by Streamlit, usually `http://localhost:8501`.

The app loads `07_ML_Dataset_with_CE_Energy_Scenarios.csv` and the existing
`xgboost_model.joblib`. If no compatible `energy_surrogate.joblib` exists, the
app trains the energy surrogate from eligible dataset rows and saves it beside
the app for reuse.

## Models and assumptions

- **Oil yield:** `Oil_Yield_wt_pct`, predicted by the supplied XGBoost model.
- **Energy:** `CE_SEC_MJ_per_kg_feed`, estimated using calculated useful heat
  and a baseline of 20% system heat loss and 70% heater efficiency.
- The energy calculation script also evaluates 10%, 20%, and 30% heat loss
  with 50%, 70%, and 85% heater efficiency.
- The `58,620 °C/min` heating-rate entries associated with `Mastral2006` are
  treated as missing for energy-model training and optimization bounds. The
  energy pipeline median-imputes missing numeric features.
- Oil-yield optimization is constrained to predictions from 0% through 100%.

The heat-loss and heater-efficiency settings are assumptions, not optimized
variables. To revise them, update the scenarios and baseline calculation in
`ce_model.py`, regenerate the CE results, point the app to the updated
energy-scenario dataset, and rebuild the cached energy surrogate before using
the changed SEC estimates.

## Project files

### Application and trained models

| File | Purpose |
|---|---|
| `app.py` | Streamlit prediction and NSGA-II optimization application. |
| `xgboost_model.joblib` | Existing trained oil-yield model used by the app. |
| `energy_surrogate.joblib` | Cached energy surrogate created and reused by the app. |
| `requirements.txt` | Python package versions for the project. |

### Datasets and calculated energy results

| File | Purpose |
|---|---|
| `03_FINAL_ML_Dataset (2).csv` | Dataset used by default when training the XGBoost model. Retain it if the model-training script will be used. |
| `07_ML_Dataset_with_CE_Energy_Scenarios.csv` | Main app dataset with energy calculations and optimization eligibility. |
| `08_CE_Model_Results.csv` | CSV output generated by the energy-calculation script. |
| `08_CE_Model_Results.xlsx` | Spreadsheet output with dataset and SEC scenario summary sheets. |

### Training and analysis scripts

| File | Purpose |
|---|---|
| `train_xgboost.py` | Trains and validates an XGBoost model using grouped, paper-wise splitting; running it replaces `xgboost_model.joblib` and writes `xgboost_results.png`. |
| `ce_model.py` | Calculates SEC scenarios and writes the `08_CE_Model_Results` files. |
| `run_nsga2_optimisation.py` | Runs the separate offline, experiment-candidate-based NSGA-II analysis and writes outputs to `09_NSGA2_Results`. |
| `plot_nsga2_results.py` | Creates plots from the offline NSGA-II result files. |
| `check_complete_optimisation_rows.py` | Checks complete eligible-row counts for proposed optimization feature combinations. |
| `check_optimisation_ranges.py` | Prints eligible numeric ranges and categorical options. |
| `check_optimisation_scenarios.py` | Summarizes data coverage by plastic and reactor type. |
| `compare_datasets.py` | Compares feed-rate values between the original and energy-scenario datasets. |
| `inspect_extreme_records.py` | Inspects selected source records, including records relevant to unusual values. |
| `investigate_ranges.py` | Prints numeric distributions and investigates extreme values and missingness. |

### Generated outputs

`xgboost_results.png` is the training script's actual-versus-predicted and
feature-importance diagnostic plot. The offline optimizer result files are:

| File | Purpose |
|---|---|
| `09_NSGA2_Results/09_All_Optimisation_Candidates.csv` | Candidate experiments with predicted oil yield and SEC. |
| `09_NSGA2_Results/09_NSGA2_Algorithm_Results.csv` | Solutions returned by the offline NSGA-II run. |
| `09_NSGA2_Results/09_NSGA2_Pareto_Front.csv` | Non-dominated candidate experiments. |
| `09_NSGA2_Results/09_NSGA2_Compromise_Solution.csv` | Selected balanced solution. |
| `09_NSGA2_Results/09_NSGA2_Run_Summary.csv` | Counts and objective values from the offline run. |
| `09_NSGA2_Results/10_Pareto_Front.png` | Plot of the Pareto trade-off and compromise. |
| `09_NSGA2_Results/10_Oil_Yield_Comparison.png` | Predicted yields across Pareto candidates. |
| `09_NSGA2_Results/10_SEC_Comparison.png` | SEC values across Pareto candidates. |

These are retained analysis outputs; the Streamlit app generates its own
recommendations and CSV download.

Python's `__pycache__/` bytecode files are disposable and have been cleared.
The empty directory is a filesystem reparse point and was left in place.
